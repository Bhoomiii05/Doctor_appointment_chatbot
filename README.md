Doctor Appointment Chatbot
🚀 Overview

A full-stack Doctor Appointment Chatbot that assists users in booking, managing, and understanding healthcare services through an interactive chat interface.

The system integrates appointment scheduling, emergency assistance, prescription analysis, and multilingual support to improve user experience.

✨ Key Features
📅 Appointment Management
Book doctor appointments using Calendly integration
Reschedule appointments easily
Simple and guided chatbot-based flow
🚨 Emergency Support
Emergency option connects users to relevant doctors
Suggests doctors based on symptoms
Supports quick access to care
🎥 Video Consultation
Enables video call support with doctors
Helps users consult remotely
💊 Prescription Reader
Upload prescription images
Extracts and displays medicine details in readable format

Example Output:

Brand Name: Symmetry Foaming Hand Sanitizer - Fragrance Free with Aloe and Vitamin E
Manufacturer: Buckeye International, Inc.
Substance Name: ALCOHOL
Product Type: HUMAN OTC DRUG
Generic Name: ALCOHOL
🔍 Medicine Search
Search for required medicines
Displays relevant product details and usage info
🌐 Language Translator
Built-in translation support
Currently supports:
English
Hindi
🛠 Tech Stack
Backend: Django (Python)
Frontend: HTML, CSS, JavaScript
Database: SQLite
APIs/Tools:
Calendly (appointment scheduling)
Google Translate (via googletrans)
⚠️ Setup Note

This project was developed using Python 3.8–3.10.

Some dependencies (like googletrans) may not work properly on newer versions such as Python 3.13.

▶️ How to Run
Install Python 3.10
Create virtual environment

Install dependencies:

pip install django
pip install googletrans==4.0.0-rc1

Run the server:

python manage.py runserver
